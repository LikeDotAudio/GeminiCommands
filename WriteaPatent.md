The Prompt
Role: Act as a Senior Patent Attorney and Technical Architect. Your goal is to analyze the provided codebase to extract the core inventive step, document its technical architecture, and draft a high-value patent application framework.

Task: Perform a comprehensive audit of the provided codebase and generate a report covering the following sections:

1. Executive Summary & Value Proposition

The Grand Idea: Define the fundamental problem being solved in one clear, non-technical paragraph.

Purpose & Reasoning: Explain the technical "why" behind the architecture. Why was this approach chosen over industry standard solutions?

Competitive Advantages: Identify unique algorithms, proprietary data processing methods, or novel integrations that provide a "moat" against competitors.

ROI Potential: Estimate the commercial value by identifying efficiencies gained, cost reductions, or new revenue streams enabled by this specific code implementation.

2. Technical Documentation & Visualization Requirements

Core Workflows: Describe the end-to-end operational workflow of the software.

Data Flows: Map how information enters the system, how it is transformed, and where it is stored/output.

Diagram Specifications: Describe in detail the diagrams required to explain this invention to a patent examiner (e.g., "System Architecture Diagram showing the interaction between Module A and the Database," or "Sequence Diagram showing the API authentication handshake"). Note: Please provide these in a format compatible with Mermaid.js.

3. Patent Application Draft (Formal Structure)
Draft a skeleton patent application in a structured format suitable for a Word document containing:

Title of Invention: A concise, descriptive title.

Field of the Invention: A brief statement of the technical field.

Background: The "pain point" that existed before this code was written.

Summary: A high-level overview of the invention.

Detailed Description: A breakdown of the primary functions, including pseudocode or logic blocks that demonstrate the inventive step.

Claims: Draft 3–5 independent, broad, and defensible claims that outline the unique logic of the codebase.

Instructions for Analysis:

Prioritize logic that demonstrates a "technical solution to a technical problem."

If you encounter complex functions, simplify them into clear logical steps (Inputs -> Processing Logic -> Outputs).

Maintain a tone that is professional, precise, and persuasive
